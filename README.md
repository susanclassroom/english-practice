## 單字庫（vocab.html）

跟其他練習不同：**不綁進度、不綁段考、不分冊別、不分應用／認識**。

出版社把單字分成「應用字彙／認識字彙」，那是為了界定段考範圍；
冊別也一樣。但對複習中的國三生，跟他說某個字「看得懂就好」，
等於先告訴他有些字不值得學。會考也不會問這個字出自第幾冊。
所以這個庫刻意把兩個標籤都拿掉——**每個字都一樣重要**。

- **三種模式**：「接著練」（只出沒練過的，不重複已經練過的字）、
  「只練我還沒過的」（答錯的字留著，答對就消失）、「全部複習」。
  這三顆按鈕是「隨時練」的核心——1201 字不可能一次練完，
  學生每次進來都從上次停的地方接著往下走。
- **總進度列**：頁面最上面顯示「已經會／還沒過／還沒練到」各幾個字，
  學生看得到自己離全部練完還有多遠。
- **階段是動態的**——只顯示有題目的階。第四冊目前有三階
  （看得懂／想得起來／放進句子），第四階「會考式」要手寫情境句，之後再補。
- 第三階的填空句直接取自課本例句，四個選項由程式從同詞性的字產生，
  並且會跟著答案變化時態（答案是 socks，干擾就是 belts / bugs 而不是 belt / bug）。
- 句型類條目（`as... as...`）打不出來，自動不進拼字階。

**第 1～6 冊全部收錄完成**，另加第六冊附錄的 26 個片語動詞，
去重後 1201 字，其中 213 個是片語／詞組。

抽取流程（讀 PDF 文字層 → 依座標分欄配對單字與中文 → 去重 → 產生干擾選項）
已經自動化，六冊零失敗。第六冊附錄的片語動詞例句因欄位重疊導致斷句，
只取片語與中文，未收例句——破碎的填空題比沒有更糟。

## 會考必考字（exam-vocab.html）

不是出版社的字表，是**從 111～115 年五年會考真實考卷反推出來的**：
把五年考卷（閱讀＋聽力錄音稿）出現過的字全部抓下來，依出現頻率分級。

- 共 1277 字。第 1 級 61 字、第 2 級 63 字、第 3 級 75 字、第 4 級 79 字，
  之後每級 160～190 字，第 8 級 184 字。
- 另有 **306 個「聽力字」**：五年閱讀測驗都沒考過，只在聽力錄音稿出現。
  單獨一頁，不跟閱讀字混在一起。
- 748 個字標了「聽力也考過」——閱讀和聽力都出現的字，優先度最高。

級數本身就是教學訊息：**第 1 級只有 61 個字，先把那一級練熟**，
比起面對 1277 字的清單，學生知道下一步要做什麼。

## 一字多義（multi-sense.html）

同一個字，在不同句子裡意思不一樣——會考很愛考，但背單字表背不到。

- 243 個多義字、582 題。每題給一個句子，問畫底線的字在這裡是哪個意思。
- **489 題（84%）的句子直接出自會考真題**，其餘 93 題是自編的。
- 一樣依會考頻率分 8 級＋聽力字，第 1 級 114 題最多。

## 慣用語（idioms.html）

資料來源是十份會考考卷的實測結果：**會考平均每年只考一題慣用語**，
所以「背清單」沒有用——它下次會用你沒背過的那一個。
這一份練的是**從上下文猜意思**的能力。

分兩種，畫面上會標示：

- **固定慣用語**（`a close call`、`on the house`、`for the birds`）：有固定意思
- **言外之意**（「你明年就會知道我在說什麼了」＝我不信他會做）：沒有固定答案，要從對話推

三階：看情境猜 → 記得起來（中文選英文）→ 會考真題。
第三階的 9 條全部來自 111～115 年聽力真題，情境也是原文。

## 一份練習一份表單

八個練習頁各自帶著自己的 `GFORM` 設定區塊，現在的對應是：

| 表單 | 收哪些頁 | 課次欄寫什麼 |
|---|---|---|
| K5-2026-單字練習紀錄 | `vocab` `exam-vocab` `multi-sense` `l1-vocab` `l2-vocab` | 單字庫／會考字表／一字多義／L1單字／L2單字 |
| K5-2026-國三文法練習紀錄 | `grammar` | 文法 |
| K5-國三英文練習紀錄（舊的共用表單） | `idioms` `reading` | 慣用語／閱讀 |

同一份表單裡靠「課次」欄分辨是哪一頁，所以五份單字練習共用一份試算表也分得開。
慣用語和閱讀還沒有專屬表單，先留在原本的共用表單，之後建好再換。

**表單的七題必須全部是「簡答」、而且全部不勾必填。**
新增題目時 Google 預設是選擇題，選擇題只收事先打好的選項，
自由文字會被整筆退回（實測 HTTP 400）；必填也一樣，
「作業狀態」在沒指定作業時本來就是空的，一空就被退。
**最保險的建法是複製現成的表單**，類型和必填設定會跟著複製過來。

## 沒做完就離開，也留紀錄

原本 `sendOut()` 只在 `finish()` 裡呼叫一次——**學生做到第 12 題就關掉，
那一次完全不會留下任何痕跡**。八個練習頁現在都在檔案最後加了一段，
在 `pagehide` 和分頁被切到背景時，用 `navigator.sendBeacon` 補送一筆，
階段欄會寫「沒做完就離開　12/20 題」。

- 用 `sendBeacon` 不用 `fetch`：關頁面時 fetch 會被瀏覽器直接中斷。
- 每一回合最多補送一次，所以一回合最多兩列（中途一列＋做完一列）。
- 一題都還沒做完就離開的不記，避免只是點進來看看也產生紀錄。
- 訪客座號一樣不送。

這段是包在 IIFE 裡包住原本的 `start()` 和 `finish()`，
沒有動到任何既有函式的內容，八個檔用的是同一段程式碼。

## 換新表單：不用手抄 entry 代號

一份練習一份表單、一份試算表時，每建一份新表單就要一組新的 entry 代號。
不用進表單原始碼慢慢找，跑這個：

```bash
python3 tools/form-entries.py "https://docs.google.com/forms/d/e/XXXX/viewform"
```

網址用「傳送 → 連結」複製到的那個（`/edit` 編輯網址要登入，抓不到）。
它會印出每一題的 entry 代號，並直接組好可以貼進練習頁的 `GFORM` 區塊。

**最快的建法是複製現有表單**：開啟「K5-國三英文練習紀錄」→ 右上 ⋮ →
「建立副本」→ 改名（例如「K5-單字練習紀錄」）→ 到「回覆」分頁 →
「連結至試算表」→ 建立新的試算表。七個題目原封不動，
代號會重新產生，重跑上面的指令抓新的就好。

八個練習頁各自有自己的 `GFORM` 區塊（本來就是各存一份），
所以要幾份表單由你決定：一類一份（單字／文法／閱讀）或一頁一份都行，
改的都是同一段設定。

## 紀錄回收：表單 vs Apps Script

現在八份練習都用 Google 表單的 `formResponse` 端點，`mode:"no-cors"` 送出。
這個做法能用，但有一個先天限制：**瀏覽器拿不到回應，所以頁面永遠不知道送出成功了沒**。
送失敗只能靠猜（目前的補救是失敗就存進 `store.pending`，下次開頁再補送）。

`apps-script/record-endpoint.gs` 是另一條路：部署成 Google Apps Script 網頁應用程式，
練習頁 POST 過去，**伺服器會回一個 `{ok:true}`**，所以頁面可以：

- 明確顯示「✓ 已送出」或「✗ 還沒送出，請按重新送出」
- 失敗時自動重試，再失敗就給學生一顆重送按鈕
- 欄位想加幾個就加幾個，不必受表單那 7 欄限制
- 寫進哪一份試算表由你決定，一份練習一份表

部署步驟寫在那個 `.gs` 檔的開頭註解。部署完把 `/exec` 網址提供出來，
就能把 `vocab-solo.html` 的 `GFORM` 區塊換成這條路。

## 班級名單

八份練習都用同一套名單設定（在每個檔案最上面的設定區）：

```js
const CLASSES = {
  a: { name:"國三班", seats:[
    {n:"01", s:"靜"}, {n:"02", s:"若"}, ...
  ]}
};
```

`n` 是座號，`s` 是名字的一個字。學生看到的是「01 靜」，
公開的原始碼裡沒有任何完整姓名。

名單最後有一個 `{n:"00", s:"訪客", guest:true}`，是老師自己試做用的：
它會出現在座號選單（虛線框），但**不算進全班統計、不會送進 Google 試算表**，
所以老師先試玩不會弄髒學生資料。

**要加第二班**：在 `a: {...}` 後面補一個逗號，再貼一組

```js
, b: { name:"週四班", seats:[ {n:"01", s:"○"}, {n:"02", s:"○"} ] }
```

然後把連結改成 `...?c=b` 發給那一班。八份都要改同一段（名單是各自獨立的）。
網址代號打錯會自動退回第一班，不會出錯或標錯紀錄。

紀錄送到試算表時，座號欄會寫成 `A-01`、`B-03` 這種格式，
所以**不用動 Google 表單**，用篩選就能分開看兩班。
每班在裝置上的練習紀錄也是分開存的，共用電腦不會混到。

## 一頁一練習，沒有出口

練習頁**刻意不放任何通往其他頁的連結**。學生拿到哪一份的網址，
就只看得到那一份——點不到別的練習，也看不到還有哪些練習存在。

理由是專注：國三生打開「單字庫」就該練單字，不該在八份練習之間逛來逛去，
挑最輕鬆的那個做。要練哪一份由老師發網址決定。

所以發作業有兩種方式，看你要哪一種：

| 你發的網址 | 學生看到的 |
|---|---|
| `.../english-practice/` （首頁） | 八份練習都看得到，本週作業那份標黃，其他淡化 |
| `.../english-practice/vocab.html` （單頁） | 只有單字庫，沒有別的入口 |

首頁本身沒有動，你要用總表模式隨時可以用；從首頁點進練習後，
學生用瀏覽器的上一頁鍵就能回總表。

**注意**：這是「看不到入口」，不是「進不去」。repo 公開、每一頁都是公開網址，
知道檔名的人直接打網址還是開得了。目的是讓學生專心，不是防駭。

## 每週指定作業（首頁）

打開 `index.html`，最下面的 script 只有兩行要改：

```js
const THIS_WEEK = "grammar";          // 這週要做的：l1／l2／grammar／reading／all
const DUE       = "9/22（週二）上課前";
```

被指定的那一份會在首頁標成「本週作業」並 highlight，其他七份會淡化成
「這週不用做，想多練可以點」。學生只要記首頁一個網址就好。

`THIS_WEEK` 可以填任何一份練習的代號：
`bank` 單字庫／`exam` 會考必考字／`multi` 一字多義／`l1`／`l2`／
`grammar`／`idioms`／`reading`，或 `all`（八份全做）。

## 每週要改的地方

打開 `l1-vocab.html` 或 `l2-vocab.html`，找到最上面的設定區：

```js
const SEATS = 15;              // 班上座號到幾號
const TEACHER_CODE = "2026";   // 老師檢視的密碼

const HOMEWORK = {
  due: "9/15（週二）上課前",    // 繳交日
  tasks: [
    { stage:0, pass:26 },      // 第一階 看得懂：至少對 26 題
    { stage:1, pass:20 }       // 第二階 想得起來：至少對 20 題
  ]
};
```

改完存檔，push 上去就生效。

文法頁（`grammar.html`）多一個 `group`，可以指定這週只練哪一個文法點：

```js
const HOMEWORK = {
  group: "pp",   // pp 現在完成式／tag 附加問句／that 名詞子句／it 虛主詞／emo 情緒動詞／all 全部
  tasks: [ { stage:0, pass:13 }, { stage:2, pass:12 } ]
};
```

題庫比每回合的題數多（`ROUND = 15`），每次進去都是隨機抽題，重練不會一模一樣。

閱讀頁（`reading.html`）用 `reading` 指定這週讀哪一篇：

```js
const HOMEWORK = {
  reading: "costco",   // costco 好市多卡／mona 蒙娜麗莎／fukushima 福島核廢水／all 全部
  tasks: [ { stage:0, pass:8 }, { stage:3, pass:2 } ]
};
```

閱讀的四階是四種能力，不是四種難度：
第一階「讀之前」先用中文補背景再認生字，第二階「找得到」練回文章定位，
第三階「讀得懂」練代名詞指涉與從上下文推論，第四階才是會考原題。
老師檢視會直接指出全班是卡在生字、卡在找不到，還是卡在讀不懂。

## 學生紀錄

作答紀錄會自動送到 Google 表單「K5-國三英文練習紀錄」，
在對應的試算表就能看到誰做了、做了幾階、哪些字還沒過。

學生不需要登入，也不會看到表單。

## 老師檢視

練習頁最下面有「老師檢視」，點了會在頁面內出現密碼欄（不用瀏覽器彈窗，
LINE 內建瀏覽器也能用），密碼是 `TEACHER_CODE` 那一行設定的值。
可以看進度、最常錯的字，點座號可以看單一學生的學習報告（可列印給家長）。

**這一頁叫「這台裝置上的作答狀況」，名字是認真的**：資料讀的是這台裝置的
localStorage，學生用自己手機練的不會出現在這裡。**全班的完整資料一律看
Google 試算表**，老師檢視只適合上課時用教室那台電腦即時看。

註：這個 repo 是公開的，密碼寫在原始碼裡擋不住刻意要看的人。
頁面內只有座號和單字對錯，沒有學生姓名。
